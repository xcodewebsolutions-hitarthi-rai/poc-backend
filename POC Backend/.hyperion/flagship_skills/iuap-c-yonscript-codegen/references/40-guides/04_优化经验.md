# 公有云项目开发经验沉淀 - 优化点汇总

## 一、iuap-c-yonscript-codegen（后端YonScript开发）优化点

### 1. YonSQL查询规范（新增）

**问题**：开发过程中多次混淆数据库表查询思维和 YonQL 业务对象查询思维

**规范**：
- ✅ 必须使用 `ObjectStore.queryByYonQL` 进行业务对象查询
- ❌ 禁止把 YonQL 当成数据库表查询来写
- ✅ YonQL 以 `uri`、`domain`、业务字段路径为核心
- ✅ 特征组字段需要通过别名访问（如 `contacterCharacter.soatoemail as soatoemail`）
- ✅ 表中没有 `dr` 字段时，不要添加 `and dr = 0` 条件

**示例**：
```javascript
// ✅ 正确：使用YonSQL业务对象查询
var yonSql = "select id, merchantId, email, isDefault, " +
             "contacterCharacter.soatoemail as soatoemail, " +
             "contacterCharacter.soaccemail as soaccemail " +
             "from aa.merchant.Contacter " +
             "where merchantId = '" + customerId + "'";
var result = ObjectStore.queryByYonQL(yonSql, 'productcenter');

// ❌ 错误：按数据库表思维拼查询
// 不允许用 tableName / 底层列名 / 原生 SQL 方式组织 YonQL
```

### 2. 发送邮件规范（新增）

**问题**：开发过程中混淆了API调用和平台内置函数

**规范**：
- ✅ 必须使用平台内置的 `sendMessage(messageInfo)` 函数发送邮件
- ❌ 禁止使用 `ObjectStore.openLinkerPure` 调用API发送邮件
- ✅ 元数据专属参数（`others`）必须包含8个字段
- ✅ 特征组字段需要通过别名访问

**示例**：
```javascript
// ✅ 正确：使用sendMessage发送邮件
var messageInfo = {
  sysId: 'diwork',
  tenantId: env.tenantId,
  templateCode: templateCode,
  busiData: busiData,
  mailReceiver: toEmails,
  mailCc: ccEmails,
  channels: ['mail'],
  groupCode: 'businessprocess',
  others: {
    domain: 'yonbip-fi-earap',
    billId: billItem.id,
    busiObjId: billItem.id,
    tenantId: env.tenantId,
    yhtToken: env.token,
    appCode: 'EFI',
    businessObjectCode: 'FIAR.FIAR.ARStatement',
    billNo: 'ARStatement'
  }
};
var result = sendMessage(messageInfo);

// ❌ 错误：使用openLinkerPure调用API
var resultString = ObjectStore.openLinkerPure('POST', url, '', body, header);
```

### 3. 错误处理规范（新增）

**问题**：异常处理不完善，导致问题难以定位

**规范**：
- ✅ 使用try-catch包裹关键逻辑
- ✅ 添加详细的日志记录
- ✅ 异常时返回友好的错误信息

**示例**：
```javascript
try {
  var result = ObjectStore.queryByYonQL(yonSql, domain);
  console.error('【MyAPIHandler】查询结果: ' + JSON.stringify(result));
  return result || [];
} catch (e) {
  console.error('【MyAPIHandler】查询异常: ' + e.message);
  console.error('查询异常堆栈: ' + (e.stack || '无'));
  return [];
}
```

## 二、iuap-c-mdf-codegen（前端MDF开发）优化点

### 1. 按钮事件注册（新增）

**问题**：混淆了自定义按钮和标准动作的事件注册方式

**规范**：
- ✅ 自定义按钮使用 `click` 事件
- ✅ 标准动作使用 `doAction` 方法
- ✅ 按钮编码必须唯一

**示例**：
```javascript
// ✅ 正确：自定义按钮使用click事件
var btnSendEmail = viewModel.get('button11md');
if (btnSendEmail) {
  btnSendEmail.on('click', function () {
    // 按钮点击逻辑
  });
}

// ❌ 错误：自定义按钮使用doAction
doAction: function (name, viewModel) {
  if (name === 'btnSendEmail') {
    // 错误：自定义按钮不应使用doAction
  }
}
```

### 2. API脚本调用（新增）

**问题**：混淆了API脚本调用和接口调用

**规范**：
- ✅ 公有云项目使用 `cb.rest.invokeFunction` 调用API脚本
- ❌ 禁止使用 `viewModel.setProxy` 或 `cb.rest.DynamicProxy.create`

**示例**：
```javascript
// ✅ 正确：使用invokeFunction调用API脚本
cb.rest.invokeFunction(
  'EAR.backDesignerFunction.GetMessageTemplates',
  {},
  function (err, res) {
    if (err) {
      cb.utils.alert('获取失败：' + err.message, 'error');
      return;
    }
    // 处理结果
  }
);

// ❌ 错误：使用setProxy调用接口
var proxy = viewModel.setProxy({
  getMessageTemplates: {
    url: '/yonbip/fiar/api/getMessageTemplates',
    method: 'POST'
  }
});
```

### 3. 弹窗实现（新增）

**问题**：`cb.utils.confirm` 的 `content` 参数不支持HTML渲染

**规范**：
- ✅ `cb.utils.confirm` 的 `content` 参数不支持HTML渲染
- ✅ 使用原生JavaScript创建DOM元素
- ✅ 使用固定宽度或全角空格补齐对齐

**示例**：
```javascript
// ✅ 正确：使用原生JavaScript创建DOM元素
function createCustomDialog() {
  var dialogContainer = document.createElement('div');
  dialogContainer.style.cssText = 'position: fixed; top: 0; left: 0; width: 100%; height: 100%; background: rgba(0,0,0,0.5); z-index: 9999;';
  
  var dialogContent = document.createElement('div');
  dialogContent.style.cssText = 'background: #fff; border-radius: 4px; width: 500px;';
  
  // ...
}

// ❌ 错误：使用HTML字符串
var contentHtml = '<div style="max-height: 300px;">...</div>';
cb.utils.confirm({
  content: contentHtml  // 不支持HTML渲染
});
```

### 4. 布局对齐（新增）

**问题**：按钮宽度不一致导致错位

**规范**：
- ✅ 按钮宽度不一致时使用全角空格补齐
- ✅ 使用固定宽度样式保持对齐
- ✅ 使用 `●` 和 `○` 作为选中/未选中标记（宽度一致）

**示例**：
```javascript
// ✅ 正确：使用全角空格补齐
var dynamicActions = templateList.map(function (item, index) {
  var isSelected = index === selectedIndex;
  var prefix = isSelected ? '● ' : '○ ';
  return {
    text: prefix + item.templateName,
    type: isSelected ? 'primary' : 'default',
    style: { textAlign: 'left' }
  };
});
```

## 三、常见问题及解决方案

### 问题1：YonSQL查询失败
**原因**：使用了数据库表查询思维，或字段路径不符合业务对象语义
**解决**：回到 `uri/domain/字段/条件` 四要素，按业务对象重写 YonQL

### 问题2：邮件发送失败
**原因**：使用了错误的API调用方式
**解决**：使用 `sendMessage(messageInfo)` 函数

### 问题3：按钮点击无响应
**原因**：使用了错误的事件注册方式
**解决**：自定义按钮使用 `click` 事件

### 问题4：弹窗HTML不渲染
**原因**：`cb.utils.confirm` 不支持HTML
**解决**：使用原生JavaScript创建DOM元素

### 问题5：布局错位
**原因**：按钮宽度不一致
**解决**：使用全角空格补齐或固定宽度
