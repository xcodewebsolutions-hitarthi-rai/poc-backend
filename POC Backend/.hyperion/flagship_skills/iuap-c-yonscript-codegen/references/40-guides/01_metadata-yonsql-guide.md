# YonScript 元数据到 YonSQL 使用指南

> **加载时机**：YonScript 后端脚本需要用 YonSQL 查询业务对象时。
> **定位**：辅助总览，不替代强约束门禁。
> **说明**：平台执行方法名仍为 `ObjectStore.queryByYonQL`。

---

## 一、核心原则

YonSQL 只按业务对象查询。生成代码前必须先确认：

1. `uri`
2. `domain`
3. 字段名
4. 查询条件
5. 字段类型

字段类型必须从元数据确认，至少区分：基本类型、参照、特征、子表、平行表、多选引用。

---

## 二、元数据来源

| 信息 | 来源 |
|---|---|
| 业务对象 URI | `_entityInfo.uri` |
| domain | `_entityInfo.domain` |
| 基本字段 | `attributes[].name` |
| 参照字段 | `attributes[].refUri` |
| 子表 | `tables.<key>` |
| 特征组/特征字段 | `characterGroups` |
| 平行表 | 独立业务对象 URI/domain + 关联键 |

`tableName`、`schema`、`dbColumnName` 只用于理解或核对，不用于拼 YonSQL。

---

## 三、字段类型到写法

| 字段类型 | 写法 |
|---|---|
| 基本类型 | 当前实体直接查询 |
| 参照 | 外层显式选参照字段，优先嵌套查询目标字段 |
| 特征 | 外层显式选特征组，内部按特征编码查询 |
| 子表 | 外层选主实体 `id`，内部查询子表字段 |
| 平行表 | 分步查询后用关联键在脚本合并 |
| 多选引用 | 外层选 `id`，内部先选多选字段再嵌套档案字段 |

详细字段命名规则见 `../10-common/03_字段命名契约.md`。

---

## 四、禁止事项

- 禁止按数据库表名或底层特征表组织查询。
- 禁止用 `dbColumnName` 代替字段名。
- 禁止把参照、特征、子表、平行表按基本字段处理。
- 禁止默认 `select *`。
- 禁止把 `_code` / `_name` 当成当前实体字段直接查询。
- 禁止元数据查询失败后凭经验继续拼 YonSQL。
