# 远程调用（API 调用代码示例）

> **V8语言限制说明**：YonScript（V8语言）只能使用以下4种远程调用API，无法使用原生HTTP客户端。
>
> | API | 用途 | 鉴权方式 |
> |-----|------|---------|
> | `ObjectStore.openLinker` | BIP内部API | 自动认证 |
> | `ObjectStore.openLinkerPure` | BIP内部API（跨环境）| appKey/appSecret |
> | `ObjectStore.postman` | **跨租户/三方系统** | **手动鉴权** |
> | `ObjectStore.nccLinker` | NCC/高级版 | nccEnv对象 |
>
> **核心结论**：调用SAP/浪潮/金蝶等三方系统的**唯一方式**是 `ObjectStore.postman`。
>
> **API 调用决策表**、**safeJsonParse 规范**、**openLinker/postman 选择标准**等统一在 [../00-governance/01_技术规范.md](../00-governance/01_技术规范.md) 中维护。
> 本文档仅提供**具体调用代码**（不带决策，不带规范重复）。
> **三方系统统一封装**见 [../30-scenes/03_三方集成封装.md](../30-scenes/03_三方集成封装.md)。

## BIP内部API

### openLinker（自动认证）

使用当前租户身份调用开放平台API。详细规范见 [../00-governance/01_技术规范.md 规范 3](../00-governance/01_技术规范.md#规范3bip内部api调用)。

```javascript
var env = ObjectStore.env();
var body = { code: request.code };
var url = env.url + '/iuap-api-gateway/yonbip/hrcloud/HRCloud/getStaffDetail';
var resultString = ObjectStore.openLinker('POST', url, 'jrzjzhgl', body);
var result = safeJsonParse(resultString, { longFields: [], lengthThreshold: 16 });
```

### openLinkerPure（自定义身份）

使用 appKey/appSecret 绑定的身份调用，支持跨环境调用。

```javascript
var header = {
  appkey: 'your-appkey',
  appsecret: 'your-appsecret'
};
var url = 'https://bip-test.yonyoucloud.com/iuap-api-gateway/yonbip/digitalModel/project/detail?id=32132';
var resultString = ObjectStore.openLinkerPure('GET', url, 'your-appcode', null, header);
var result = safeJsonParse(resultString, { longFields: [], lengthThreshold: 16 });
```

## 跨租户/三方

### postman（REST接口）

调用REST接口，不仅限于本系统。详细规范见 [../00-governance/01_技术规范.md 规范 4](../00-governance/01_技术规范.md#规范4跨租户三方调用)。

```javascript
var header = { 'Content-Type': 'application/json;charset=UTF-8' };
var url = env.url + '/yonbip-mid-sscpf/test/testScript';
var resultString = ObjectStore.postman('post', url, header, param);
var result = safeJsonParse(resultString, { longFields: [], lengthThreshold: 16 });
```

### 表单方式提交

```javascript
var header = {
  authoration: 'apicode',
  apicode: 'xxx',
  'Content-Type': 'application/x-www-form-urlencoded'
};
var body = { domain: 'APILink-finance', imageData: imageData };
var resultString = ObjectStore.postman('post', url, header, body, 'form');
```

### NCC接口

调用NCC服务接口，需传入nccEnv认证对象。

```javascript
var header = { 'content-type': 'application/json;charset=utf-8' };
var nccEnv = {
  clientId: 'your-clientId',
  clientSecret: 'your-clientSecret',
  pubKey: 'your-rsa-public-key',
  grantType: 'client_credentials',
  tokenUrl: 'https://xxx:22278/nccloud/opm/accesstoken'
};
var result = ObjectStore.nccLinker('POST', url, header, request.data, nccEnv);
```

### 三方系统调用（SAP/浪潮等）

**V8语言只能通过 `ObjectStore.postman` 调用三方系统**。

**推荐方式**：使用统一封装（见 [24_三方集成封装规范.md](24_三方集成封装规范.md)）

```javascript
// 推荐：使用统一封装
var func = extrequire('GTxxx.Integration.SAPConnector');
var result = func.execute({
    apiPath: '/api/sap/recbill/insert',
    body: requestBody
});
```

**基础方式**：直接使用 postman（不推荐，缺乏错误处理）

```javascript
// 不推荐：直接使用 postman
var header = { 'Content-Type': 'application/json;charset=UTF-8' };
var url = 'https://sap.example.com/api/recbill/insert';
var resultString = ObjectStore.postman('POST', url, header, requestBody);
var result = safeJsonParse(resultString, { longFields: [], lengthThreshold: 16 });
```

## 其他脚本

### extrequire（调用其他后端脚本）

通过脚本编码调用另一个后端脚本。

```javascript
var func = extrequire('GT41287AT68.backDefaultGroups.externfunc');
var res = func.execute({ key: 'value' });
```

### 调用其他脚本获取token后调用API

```javascript
// 1. 获取token
var getTokenFun = extrequire('GT0000TEN0.token.getToken');
var token = getTokenFun.execute();
var accessToken = token.access_token;

// 2. 手动拼接token调用
var url = ObjectStore.env().url + '/iuap-api-gateway/yonbip/hrcloud/HRCloud/getStaffDetail?access_token=' + accessToken;
var body = { id: staffId };
var apiResponse = ObjectStore.postman('post', url, {}, body);
var staffRes = safeJsonParse(apiResponse, { longFields: [], lengthThreshold: 16 });
```
