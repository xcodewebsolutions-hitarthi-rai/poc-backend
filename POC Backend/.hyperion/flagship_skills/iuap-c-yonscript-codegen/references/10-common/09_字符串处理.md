# 字符串处理

| 函数 | 说明 |
|------|------|
| `replace(text, pattern, replacement)` | 替换字符或正则匹配的子串 |
| `split(text, separator, limit?)` | 分割字符串为数组，可指定返回数组最大长度 |
| `join(array, separator)` | 把数组中所有元素放入一个字符串 |
| `includes(text, substring)` | 判断字符串是否包含指定子字符串 |
| `trim(text)` | 删除字符串头尾空格 |
| `substring(text, start, end)` | 提取两个指定下标之间的字符 |
| `capitalize(text)` | 字符串第一个单词首字母变大写 |
| `capitalizeEveryWord(text)` | 字符串每一个字母变大写 |
| `prefixInteger(num, length)` | 按指定长度为数字前面补零 |
| `json2string(obj)` | JavaScript对象转换为字符串 |
| `string2json(str)` | 字符串转换为JavaScript对象 |
| `xml2json(xml)` | xml对象转换为json对象 |
| `json2xml(obj)` | json对象转换为xml对象 |
| `UrlEncode(url)` | 对url进行编码 |
| `UrlDecode(url)` | 对url进行解码 |

### 线上实际示例

**replace — 替换仓库名称中的关键字：**

```javascript
var GwarehourseName = reswarehourse[0].name.replace('套件', '子件');
```

**split + trim — 处理逗号分隔的组织ID：**

```javascript
var orgs = request.orgs
  .split(',')
  .map(function (id) { return "'" + id.trim() + "'"; })
  .join(',');
```

**split — 解析许可证内容：**

```javascript
var datas = JSON.parse(split(content, ';', 4));
var param1 = Base64Decode(datas[0]);
```

**substring — 截取日志报文：**

```javascript
console.error('请求报文' + JSON.stringify(request).substring(0, 1000));
```

**includes — 判断产品列表是否包含目标ID：**

```javascript
if (productIdList.includes(item.productId)) {
  // 已存在则跳过
}
```

**UrlEncode — URL编码查询参数：**

```javascript
var url = env.url + '/iuap-api-gateway/yonbip/hrcloud/payfile/queryWaPayfileDetailByCond?schemeCode=' + UrlEncode(request.code) + '&payPeriod=' + request.payPeriod;
```
