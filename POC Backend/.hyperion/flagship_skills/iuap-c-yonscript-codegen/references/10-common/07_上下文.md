### 获取用户信息 — ObjectStore.user()

获取当前用户和租户信息。

```javascript
var user = ObjectStore.user();
// user.id       - 用户ID
// user.name     - 用户名
// user.orgId    - 组织ID
// user.deptId   - 部门ID
// user.tenantId - 租户ID
// user.mobile   - 手机号
// user.email    - 邮箱
// user.code     - 用户编码
// user.staffId  - 员工ID
```

返回结构：

```json
{
  "id": "99ea7655-00a2-4bda-b23c-19ade37ea574",
  "name": "123u8c_vip@163.com2",
  "orgId": "1526180336229679105",
  "deptId": "1526180671237128197",
  "tenantId": "0000L6YTYEY5FUZPXE0000",
  "mobile": "+86-17609888888",
  "email": "u8c_vip@163.com",
  "code": "00000001",
  "staffId": "1529890243089530888"
}
```

**线上实际示例：**

```javascript
var AbstractAPIHandler = require('AbstractAPIHandler');
class MyAPIHandler extends AbstractAPIHandler {
  execute(request) {
    var user = ObjectStore.user();
    var userStaffId = user.staffId;
    return { userStaffId };
  }
}
exports({ entryPoint: MyAPIHandler });
```

### 获取环境信息 — ObjectStore.env()

获取租户、token、域名、业务日期等环境信息。

```javascript
var env = ObjectStore.env();
// env.url          - 系统域名（如 https://bip-test.yyuap.com）
// env.tenantId     - 租户ID
// env.token        - yht_access_token
// env.wb_at        - wb_at令牌
// env.businessDate - 业务日期（如 2025-12-11）
```

返回结构：

```json
{
  "premises": false,
  "tenantId": "0000L6YTYEY5FUZPXE0000",
  "token": "bttYVAzL0RnR3hjW...",
  "url": "https://bip-test.yyuap.com",
  "wb_at": "LMjrpmsjjPywKbpaSNGCm4rPs76njsdrs",
  "businessDate": "2025-12-11"
}
```

### 获取当前登录用户上下文 — AppContext()

获取当前登录用户上下文，返回 JSON 字符串。

```javascript
var res = AppContext();
var obj = JSON.parse(res);
// obj.currentUser.id       - 用户ID
// obj.currentUser.name     - 用户名
// obj.currentUser.tenantId - 租户ID
```

返回结构：

```json
{
  "currentUser": {
    "id": "07f90f73-24b0-41fa-83b2-8108d99cb98e",
    "name": "测试",
    "tenantId": "gb0ucj8l"
  }
}
```

### 获取多语资源 — ObjectStore.multilingual(code, defaultValue)

根据编码获取多语资源，获取不到时返回默认值。

```javascript
var multi = ObjectStore.multilingual('UID:P_YONBUILDER-MD_18E7456E04400008', '审批');
```

### 根据用户主键获取组织部门 — listOrgAndDeptByUserIds(sysId, tenantId, userids)

根据用户主键获取用户对应员工所在的组织和部门。

```javascript
var sysId = 'diwork';
var tenantId = 'lc2h5i1r';
var userids = ['38d0d16c-9f14-4729-be4b-cbaad1403afa'];
var result = listOrgAndDeptByUserIds(sysId, tenantId, userids);
```
