# 一般计算

| 函数 | 说明 |
|------|------|
| `addition(a, b)` | 加法 |
| `subtraction(a, b)` | 减法 |
| `multiply(a, b)` | 乘法 |
| `division(a, b)` | 除法 |
| `absolute(num)` | 绝对值 |

### 线上实际示例

```javascript
// 简单的金额累加计算
var totalMoney = 0;
for (var i = 0; i < items.length; i++) {
  totalMoney = addition(totalMoney, items[i].money);
}
```
