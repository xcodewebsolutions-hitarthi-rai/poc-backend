## 查询操作

### 按ID查询 — selectById

```javascript
var object = {
  id: 'targetId',
  compositions: [{
    name: 'subTableName',
    compositions: []
  }]
};
var res = ObjectStore.selectById('entity.uri', object);
```

### 条件查询 — selectByMap

```javascript
var condition = { status: 'active', type: 'normal' };
var res = ObjectStore.selectByMap('entity.uri', condition);
```

## 新增操作

### 插入实体 — insert

```javascript
var newRecord = {
  name: '测试',
  code: 'TEST001',
  subTable: [{ name: '子表记录' }]
};
var res = ObjectStore.insert('entity.uri', newRecord, 'billNo');
```

### 批量插入 — insertBatch

```javascript
var res = ObjectStore.insertBatch('entity.uri', dataArray, 'billNo');
```

### 先查后插（不存在则新增）

```javascript
var sourceId = request.accountData.source_id;
var object = { source_id: sourceId };
var res = ObjectStore.selectByMap('AT21FBAED81C900002.AT21FBAED81C900002.k98154_jr_account', object);

if (res && res.length > 0) {
  request.accountData.id = res[0].id;
  var res1 = ObjectStore.updateById('AT21FBAED81C900002.AT21FBAED81C900002.k98154_jr_account', request.accountData, 'k98154_jr_account');
} else {
  var res2 = ObjectStore.insert('AT21FBAED81C900002.AT21FBAED81C900002.k98154_jr_account', request.accountData, 'k98154_jr_account');
}
```

## 更新操作

### 按ID更新 — updateById

```javascript
var toUpdate = { id: id, name: '新名称' };
var res = ObjectStore.updateById('entity.uri', toUpdate, 'billNo');
```

> 子表通过 `_status` 控制：`Insert`（新增）、`Update`（修改）、`Delete`（删除）

### 条件更新 — update + Wrapper

```javascript
var updateWrapper = new Wrapper();
updateWrapper.eq('orderCode', jx.orderCode).eq('org_id', jx.org_id);
var toUpdate = { close: '0' };
var res = ObjectStore.update('entity.uri', toUpdate, updateWrapper, 'billNo');
```

## 删除操作

### 按ID删除 — deleteById

```javascript
var res = ObjectStore.deleteById('entity.uri', request, 'billNo');
```

### 条件删除 — deleteByMap

```javascript
var object = { source_id: request.sourceId, dr: 0 };
var res = ObjectStore.deleteByMap('entity.uri', object, 'billNo');
```

## 异常处理

### 抛出错误阻断业务

```javascript
if (!request.orderNo) {
  throw new Error('订单号不能为空');
}
```

### try-catch 处理

```javascript
try {
  var result = ObjectStore.queryByYonQL(sql);
  if (result.length === 0) {
    throw new Error('未找到匹配数据');
  }
} catch (e) {
  throw new Error('查询失败: ' + e.message);
}
```
