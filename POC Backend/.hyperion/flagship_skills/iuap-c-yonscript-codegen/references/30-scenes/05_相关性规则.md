# 相关性规则

根据入参 `sources`（条件数组）和 `target`（结果项），通过逻辑运算执行赋值、校验、可用性等操作。

## 入参说明

| 参数 | 说明 |
|------|------|
| `request.sources` | 条件数组，每项含 `code`、`type`、`value` |
| `request.target` | 当前结果项 |

### 获取条件

```javascript
var source1 = sources.filter(function (item) {
  return item.code == "ProductType1" && item.type == "Material1";
})[0];
```

## 值范围运算

返回 `range` 数组，控制下拉/可选项范围。

```javascript
var sources = request.sources;
var target = request.target;
var range = [];

var source1 = sources.filter(function (item) {
  return item.code == "ProductType1" && item.type == "Material1";
})[0];

var source2 = sources.filter(function (item) {
  return item.code == "ProductType2" && item.type == "Material2";
})[0];

if (source1 != undefined && source1.value == "D-Strip1" && source2 != undefined && source2.value == "D-Strip2" && target != undefined) {
  range = ["a", "b", "c", "e"];
} else if (source1 != undefined && source1.value == "D-Strip1" && source2 != undefined && source2.value == "D-Strip2" && target == undefined) {
  range = ["1", "2", "3", "4"];
}

return { range: range };
```

## 校验运算

返回 `validityCode`（1-合法，2-不合法）和 `message`（不合法时的提示信息）。

```javascript
var sources = request.sources;
var target = request.target;
var validityCode = 0;
var message = "";

var source1 = sources.filter(function (item) {
  return item.code == "ProductType1" && item.type == "Material1";
})[0];

var source2 = sources.filter(function (item) {
  return item.code == "ProductType2" && item.type == "Material2";
})[0];

if (source1 != undefined && source1.value == "D-Strip1" && source2 != undefined && source2.value == "D-Strip2" && target != undefined) {
  validityCode = 2;
  message = "错误描述";
} else if (source1 != undefined && source1.value == "D-Strip1" && source2 != undefined && source2.value == "D-Strip2" && target == undefined) {
  validityCode = 1;
  message = "";
}

return { validityCode: validityCode, message: message };
```

```javascript
  availability = 2;
} else if (source1 != undefined && source1.value == "D-Strip1" && source2 != undefined && source2.value == "D-Strip2" && target == undefined) {

```
