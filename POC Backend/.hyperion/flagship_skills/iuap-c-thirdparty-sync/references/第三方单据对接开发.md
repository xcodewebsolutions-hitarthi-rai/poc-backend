# 第三方单据对接开发指南

本文档提供第三方系统集成的完整开发流程，适用于WMS、LIMS、MES等第三方系统的对接场景。

---

## 1. 对接方式判断

第三方单据对接需要先判断使用哪种方式：

| 对接方式 | 适用场景                        | 实现方式 |
|--------|-----------------------------|----------|
| rule规则 | 需要在单据保存/提交等时机触发第三方集成逻辑      | 实现 IYpdCommonRul 接口 |
| plugin插件 | 需要在单据生命周期各节点做处理             | 继承 AbstractBillPlugin |
| 页面按钮调后端接口 | 用户在页面点击按钮触发第三方调用            | 暴露外部接口（Controller） |
| 事件中心监听 | 跨系统异步解耦，客开在BIP事件中心订阅，再推送第三方 | 事件监听开发 |

**判断原则**：
- 页面按钮触发的对内调用 → 页面按钮调后端接口（Controller暴露）
- 单据保存/提交时自动触发 → rule规则 或 plugin插件
- 跨系统异步解耦 → 事件中心监听
- 根据调用接口的返回结果回写单据 → - IBillRepository（推荐）：适用于本领域单据 ； IYmsJdbcApi：适用于非本领域单据 ； RPC调用（IComOperateApi）：通用方式

---

## 2. 第三方信息确认

在生成代码前，需要确认以下信息：

### 2.1 基础信息
- 第三方系统名称（如 WMS、LIMS、MES等）
- 第三方接口API地址
- 认证方式（Bearer Token、API Key等）

### 2.2 接口文档
- 是否有接口文档
  - 有文档：按文档实现字段映射
  - 无文档：创建TODO占位，标注需要补充的内容

### 2.3 返回值判断
- 成功/失败的判断逻辑（根据接口文档）
- 常见判断方式：
  - 状态码（如 code == 200）
  - 标识字段（如 success == true）
  - 错误信息是否存在

### 2.4 状态回写
- 需要回写的单据状态字段（如 `fsyncstatus` 同步状态）
- 错误描述字段（如 `ferrordesc`）

### 4.4 事件监听模板

```java
public class DemoRestEventListener {

    @ResponseBody
    @RequestMapping(value = "/event/demoListener", method = RequestMethod.POST)
    public Object onEvent(HttpServletRequest request) {
        // 1. 获取事件入参（字段名固定）
        String sourceID   = request.getParameter("sourceID");
        String eventType  = request.getParameter("eventType");
        String userObject = request.getParameter("userObject");
        String queueName  = request.getParameter("queueName");
        String tenantCode = request.getParameter("tenantCode");

        // 如果是基于 MDD 框架的订阅，入参会增加：
        // String tenantId       = request.getParameter("tenantId");
        // String id             = request.getParameter("id");
        // String yhtAccessToken = request.getParameter("yht_access_token");

        // 2. 幂等处理（非常关键）
        //    建议以事件中心的 eventId 或业务主键做幂等键
        if (alreadyProcessed(sourceID, eventType, userObject)) {
            // 注意：已经处理过也要返回 success = "true"
            // 否则事件中心会认为失败并按重试策略继续重试
            Map<String, String> response = new HashMap<>();
            response.put("success", "true");
            response.put("msg", "repeat request, ignore");
            return response;
        }

        // 3. 业务处理（写库 / 调用其他服务 / 发 MQ 等）
        try {
            handleBusiness(sourceID, eventType, userObject, tenantCode, queueName);

            // 4. 成功返回
            Map<String, String> response = new HashMap<>();
            response.put("success", "true"); // 必须是字符串 "true"
            response.put("msg", "ok");
            return response;
        } catch (Exception e) {
            // 5. 失败返回
            //    - 事件中心会根据监听的重试策略进行重试
            Map<String, String> response = new HashMap<>();
            response.put("success", "false");
            response.put("msg", e.getMessage());
            return response;
        }
    }
```
